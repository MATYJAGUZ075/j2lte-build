# FIX-0001 — DTB `_04` primero (rev 4)

## Problema
LOS20 Build 1 queda en logo Samsung 5 min, sin animación ni USB/ADB.

## Evidencia
- `head.S` usa el primer DTB anexado a `zImage`; orden era `_00→_04`.
- `model_info-hw_rev`: `_04:[4,255]`; hardware `ro.revision=4` (`J200MUBU2ARB1`).
- Display/panel común a las 5 variantes; difieren regulador cámara, touch, GPIOs, audio.

## Hipótesis
El kernel tomaba el DTB `_00` (rev 0) en hardware rev 4; poner `_04` primero entregaría la config correcta de periféricos.

## Archivos modificados
- `kernel/samsung/exynos3475/arch/arm/configs/lineage-j2lte_defconfig:531`

## Cambio realizado
```
_00 _01 _02 _03 _04  →  _04 _03 _02 _01 _00
```
en `CONFIG_BUILD_ARM_APPENDED_DTB_IMAGE_NAMES`.

## Por qué este cambio
Alinear el DTB efectivo con la revisión de hardware del SM-J200M.

## Riesgos
Display común a todas las variantes: el cambio no podía afectar el takeover de pantalla; periféricos recibirían otra config.

## Build de validación
`mka bootimage` + flash BOOT + prueba física.

## Resultado
Se generó bootimage, se probó físicamente: el dispositivo siguió detenido en el logo Samsung, sin USB/ADB. Sin cambios de síntoma.

## Estado
DESCARTADO.

## Reversión
Restaurar el orden original `_00 _01 _02 _03 _04` (coincide además con el kernel LOS19 de referencia). Solo esa línea, sin otros cambios.
